# Wireframes

Lo-fi structural specs for the UI roadmap (W-numbers, delivered). Each PNG carries a
"RULES CHECK + GROUNDING" annotation panel: bare numbers cite rules in
`docs/UX_AUTHORING_RULES.md`; "Grounded in" lines cite backend endpoints/fields as understood at
wireframing time — later re-verified against HEAD; the divergences found then are binding over
the PNGs. In-frame cross-references
to other frame ids (e.g. a frame's mention of a later iteration of another frame) are design-history, not citations.

Wireframes bind layout, IA, content, copy register, state encoding and interaction targets —
**not** visual style: screens render in the ratified dark token language (`docs/DESIGN_SYSTEM.md`),
not the sketch style.

These frames are the complete spec set — the absence of any other frame is deliberate,
not an oversight (see the roadmap's Tier-1 decision log, 2026-07-28).

# Security policy

## Supported versions

alan is a prototype. No version is supported, and no fix, release or response time is promised.

Whoever runs a copy, or maintains a fork, is responsible for securing it.

## Reporting a vulnerability

You may report a vulnerability privately through the Security tab of the upstream template repository, the one named on the first line of `setup.template`. The address has the shape `https://github.com/<slug>/security`, where `<slug>` is that first line. Use the private vulnerability reporting found there, not a public issue. Reports are read at the maintainer's discretion.

A copy made from the template is private and has no private vulnerability reporting of its own, so a report filed against a copy reaches no one who can act on it. If `setup.template` was removed from a checkout, the upstream is the repository the copy was made from.

There is no email address for reports.
